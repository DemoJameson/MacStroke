## MacStroke 3.1.10

**新增 / Added**

- Impulse gestures: hold the gesture trigger and the wheel and the other mouse buttons become actions. Each wheel notch or momentary click fires once — wheel up/down, middle button, buttons 4 and 5 — and the preset picker gains a row of impulse tiles underneath the drawn shapes. The trigger button itself never appears there, so "Left / Right Button" always means the *other* button

  按住手势触发键时，滚轮和其余鼠标键都能当动作使：滚一格或按一下触发一次，滚轮上/下、中键、按键 4/5 都在内；预设面板在图形网格下面多出一排瞬时手势格。触发键自己不会出现在那一排，所以「鼠标左键 / 右键」永远指另一颗键

- Wheel actions reproduce Mac Mouse Fix's High smoothness / High speed scroll path instead of jumping one discrete line per notch, and Shift+wheel lands on the horizontal axis. Recorder, matcher and executor all read the same axis mapping, so they cannot disagree about what a physical roll means

  滚轮动作走的是 Mac Mouse Fix 那套「高平滑 / 高速度」滚动曲线，不再是每格硬跳一行；Shift+滚轮落水平轴。录制、匹配、执行三处共用同一份轴向换算，物理上滚的那一下不会出现三种解释

- The Hot Key action can record mouse input too: middle/side buttons and the four wheel directions. They live in the same shortcut slot a keyboard shortcut uses (`MouseShortcutCodec`: buttons from 1000, wheel from 2000), so the recorder, the rules table and `rules.json` keep one representation, and old keyboard-only rules decode unchanged

  Hot Key 动作现在也能录鼠标：中键、侧键和四个滚轮方向。它们和键盘快捷键共用同一个槽位（`MouseShortcutCodec`：按键从 1000 起、滚轮从 2000 起），录制框、规则表和 `rules.json` 只有一种表示；旧的纯键盘规则照原样解码

- The rules table's gesture column renders impulse gestures as their own glyph with a name underneath, and double-clicking any gesture cell — drawn or impulse — opens the picker again

  规则表的手势列会把瞬时手势画成自己的图标、下面带名字；双击任意一格手势（画出来的、瞬时的都算）重新打开选择面板

**修复 / Fixed**

- Closing the last window no longer quits the menu-bar app. Three layers: the delegate refuses "terminate after last window closed", `Info.plist` turns off `NSSupportsAutomaticTermination` / `NSSupportsSuddenTermination` (LaunchServices was sending a Quit AppleEvent once no window had been visible for a while), and `applicationShouldTerminate` only lets the menu's Quit through

  关掉最后一个窗口不再退出常驻菜单栏应用。三层防线：delegate 拦下「关最后一个窗口即退出」；`Info.plist` 关掉自动终止与突然终止（实测无可见窗口一段时间后 LaunchServices 会主动发 Quit AppleEvent）；`applicationShouldTerminate` 只放行菜单里的 Quit

- Recording a new gesture always draws the mouse path, even with the "mouse path" preference off — recording without seeing the trail is drawing blind

  录制新手势时始终画出鼠标轨迹，哪怕偏好里关了「鼠标路径」——录制时看不见轨迹等于盲画

- Replays during one trigger press keep using the app that was frontmost at mouse-down. Showing the transparent canvas changes `NSWorkspace.frontmostApplication`, so the second wheel notch used to land on MacStroke itself instead of the user's app

  一次按压期间的所有回放都用按下那一刻的前台应用。透明画布一显示就会改变 `NSWorkspace.frontmostApplication`，以前第二格滚轮会打到 MacStroke 自己而不是用户的应用

- The rules page's three text fields are vertically centred and their width follows the column, so text no longer sits at the top of a 25pt box and the right edge stops showing a black block from the old hard-coded 100/160/400 widths

  规则页三个文本框改成真正的单行垂直居中，宽度跟随列宽：文字不再贴在 25pt 框的顶上，右边也不再因为写死 100/160/400 溢出一块黑的

- Escape now closes the clipboard-history panel from the result list too. `NSTableView` swallowed the key inside `keyDown:` and never let it reach `cancelOperation:` on the panel, so the search field closed the window but the list did not

  历史粘贴板面板：结果列表获得焦点时 Esc 也能关窗了。`NSTableView` 在 `keyDown:` 里把 Esc 直接吃掉，既不触发自己的 `cancelOperation:`，也不往响应链上冒，于是搜索框能关、结果列表不能

**性能 / Performance**

- Impulse matching walks the rule store's own rules instead of copying the whole rule list and building an engine on every wheel notch; `matchesFilter` became internal so the store reuses the same filter semantics

  瞬时手势匹配直接遍历规则库里的规则，不再每滚一格就全量复制规则建一次引擎；`matchesFilter` 改 internal，让规则库复用同一份过滤语义

**测试 / Tests**

- Impulse gestures and the rules table gained regression coverage: glyph ink and double-click targets, the picker's click forwarding, the trigger tile staying out of the panel, and the row signature carrying `impulse` so the icon column refreshes

  瞬时手势与规则表补了回归：图标有可见墨迹、双击目标存在、面板点击转发、触发键格子不进面板、行签名带上 `impulse` 让图标列会刷新

- Screenshot pixel assertions now sample by view point instead of raw bitmap pixel. Offscreen bitmaps follow the display's backing scale, so on Retina an 800×500pt view renders to 1600×1000px and point-based coordinates landed one whole cell away; several assertions were silently skipped there and never ran at all. The mosaic cell check also anchors on the bar's own background instead of hard-coding absolute luminance

  截图取证断言改为按视图点取色。离屏位图跟着屏的 backing scale 走，Retina 上 800×500 点会渲染成 1600×1000 像素，而用例写的是点坐标，整体错位一格；其中一批断言在那种机器上原本直接被跳过，从来没跑过。打码格判据也改锚在条子自身底色上，不再写死绝对亮度

- The appearance test sampled (60,30) in a Retina bitmap, which lands in the transparent area above the recorder (alpha 0) — light assertions failed and dark ones passed vacuously. It now samples the bitmap centre

  外观测试原来按点坐标写死 (60,30)，Retina 位图上落在录制框外的透明区（alpha 0）：浅色断言失败、暗色断言虚过。改成采样位图中点

- The remote-control mirror test used `kCGImagePropertyWidth`, which does not exist and always read nil; corrected to `kCGImagePropertyPixelWidth`

  远程回显用例里的 `kCGImagePropertyWidth` 这个常量不存在，取到永远是 nil，改成 `kCGImagePropertyPixelWidth`

**注意 / Notes**

- 3.1.9 is taken by the upstream `mtjo/MacStroke` appcast, so this build is numbered 3.1.10 to keep the two packages apart. This fork's release page is not the feed the app checks; the app still follows the upstream `release` branch

  3.1.9 这个号已被上游 `mtjo/MacStroke` 的 appcast 占用，所以这一版递增到 3.1.10，避免同号不同包。本 fork 的 release 页面不是应用检查的那条 feed，应用仍走上游 `release` 分支

- Impulse gestures only exist while the trigger button is held. Outside that window the middle/side buttons and the wheel keep their native behaviour — middle-click paste, back/forward, plain scrolling

  瞬时手势只在按住触发键时成立。松开或没按触发键时，中键/侧键和滚轮都是系统原生行为：中键粘贴、前进后退、普通滚动
