## MacStroke 3.1.10

**修复 / Fixed**

- Escape now closes the clipboard-history panel from the result list too. `NSTableView` swallowed the key inside `keyDown:` and never let it reach `cancelOperation:` on the panel, so the search field closed the window but the list did not — the same panel behaved two different ways depending on which one had focus

  历史粘贴板面板：结果列表获得焦点时 Esc 也能关窗了。`NSTableView` 在 `keyDown:` 里把 Esc 直接吃掉，既不触发自己的 `cancelOperation:`，也不往响应链上冒，于是搜索框能关、结果列表不能——同一个面板两套行为

**测试 / Tests**

- Screenshot pixel assertions now sample by view point instead of raw bitmap pixel. Offscreen bitmaps follow the display's backing scale, so on a Retina Mac an 800×500pt view renders to 1600×1000px and the point-based coordinates in the tests landed one whole cell away; several assertions were silently skipped there and never ran at all

  截图取证断言改为按视图点取色。离屏位图跟着屏的 backing scale 走，Retina 上 800×500 点会渲染成 1600×1000 像素，而用例写的是点坐标，整体错位一格；其中一批断言在那种机器上原本直接被跳过，从来没跑过

- The mosaic cell check anchors its thresholds on the bar's own background instead of hard-coding absolute luminance, so a 1.5pt stroke split across a half-pixel boundary no longer reads as a solid dark block

  打码格判据改锚在条子自身底色上，不再写死绝对亮度：1.5pt 笔画落在半像素边界上被劈成两行灰时，也不会被误判成一整块暗格

- The remote-control mirror test used `kCGImagePropertyWidth`, which does not exist and always read nil; corrected to `kCGImagePropertyPixelWidth`

  远程回显用例里的 `kCGImagePropertyWidth` 这个常量不存在，取到永远是 nil，改成 `kCGImagePropertyPixelWidth`
