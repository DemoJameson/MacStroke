## MacStroke 3.1.14

**修复 / Fixed**

- The Type and Action cells in the rules table now sit on the same line as the Gesture, Filter and Description fields. The type pop-up was 27pt tall starting 5pt higher, and the action recorder started 3pt lower, so the row read as a staircase; every control in the row is now 25pt tall and centred in the 84pt row

  规则页的 Type 与 Action 两格现在和 Gesture / Filter / Description 三个输入框落在同一条线上。之前类型下拉框是 27pt 高、起点高 5pt，动作录制框起点低 3pt，整行看上去像台阶；现在一行里所有控件统一 25pt 高、垂直居中于 84pt 行

- The "Screenshot" action label is drawn around the centre of its cell instead of being pinned to the top, so it lines up with the editable fields next to it

  「截图」动作的说明文字改成按格子中心绘制，不再贴顶，和旁边可编辑的输入框对齐

- The Type column is wide enough for its longest option. At the old 96pt the system pop-up button squeezed "Screenshot" and "Apple Script" into "Screens…" and "Apple Scr…"; the column is now 114pt and Description gives up the same 18pt, so the total width is unchanged

  Type 列加宽到能装下最长的选项。旧的 96pt 下系统按钮会把「Screenshot」「Apple Script」挤成「Screens…」「Apple Scr…」；现在该列 114pt，Description 让出同样的 18pt，总宽不变

- Text and Password actions use the same 100pt field width as the hot-key recorder, so the Action column no longer has a field that stops short of the others

  Text / Password 动作的输入框改成和快捷键录制框一样的 100pt，Action 列里不再有一个短一截的框

- Long names, filters and notes are truncated at the tail when they no longer fit, instead of drawing past the cell edge into the neighbouring column

  名称、过滤器、备注过长时按尾部截断，不再越过格子边界画到隔壁列上

**注意 / Notes**

- Password rows still render as dots and still edit in a secure field: the centred cell for that column stays on the `NSSecureTextFieldCell` branch, so the masking is unchanged

  密码行仍然显示圆点、仍然在安全输入框里编辑：该列居中所用的 cell 仍留在 `NSSecureTextFieldCell` 这一支上，遮罩行为没有变化

- Nothing else in the rules page moved: column order, row height (84pt), gesture thumbnails and the Draw Gesture button keep their previous geometry

  规则页其它东西没动：列顺序、行高（84pt）、手势缩略图和「绘制手势」按钮都保持原来的几何
