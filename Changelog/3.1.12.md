## MacStroke 3.1.12

**修复 / Fixed**

- The sidebar row for the current page no longer picks up a second blue outline. With full keyboard access turned on (System Settings → Keyboard → Keyboard navigation), the window hands keyboard focus to the first row the moment it opens, and SwiftUI draws the system focus ring around the whole row on top of the accent fill — so "常规" looked like it had an extra box drawn around it

  偏好侧栏当前那一页不再多出一圈蓝框。打开「完全键盘控制」（系统设置 → 键盘 → 键盘导航）后，窗口一出现就把键盘焦点交给第一行，SwiftUI 会在整行外面再描一圈系统焦点环，叠在 accent 选中底色上 —— 看上去就像「常规」那一行被额外画了一个框

- The ring is off for every sidebar row, not just the first: the accent fill already says which page you are on, and Tab still reaches the rows (macOS 14 and later keeps them focusable without the ring; on 13 they simply leave the focus chain)

  这条对所有侧栏行生效，不只第一行：选中状态本来就由 accent 底色表达，Tab 仍然能走到这些行（macOS 14 起保留可聚焦、只是不描边；13 上则退出焦点链）

**注意 / Notes**

- Focus rings inside the pages themselves — buttons, switches, text fields — are untouched: that is the system telling you where typing will go, and it should stay

  页面内部的焦点环（按钮、开关、输入框）没有改动：那是系统在提示「键盘输入会落在哪里」，该留着

- Turn keyboard navigation off in System Settings and the outline disappears as well — this release just stops the sidebar from drawing it in the first place

  把系统设置里的键盘导航关掉，这圈框同样会消失 —— 这一版是让侧栏压根不画它
